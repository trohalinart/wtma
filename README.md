# Telegram Mini App: Погода на 7 дней

Современное мини‑приложение для Telegram Web Apps про прогноз погоды на неделю: поиск города, геолокация, карточки на 7 дней, детали по дню (осадки/ветер/восход‑закат), переключение единиц и отправка прогноза в чат через Telegram MainButton.

## Структура

- `webapp/` — статический фронтенд (HTML/CSS/JS), можно хостить на любом статическом хостинге
- `bot/` — Python‑бот, который открывает мини‑приложение и принимает данные через `sendData`

## Локальный запуск webapp

Telegram Mini Apps требуют HTTPS, но для быстрой проверки можно открыть локально в браузере:

```powershell
cd webapp
python -m http.server 8000
```

Открыть: `http://localhost:8000`

## Деплой webapp (обязательно HTTPS)

Задеплойте содержимое папки `webapp/` как статический сайт (Netlify / Vercel / GitHub Pages / Cloudflare Pages и т. п.).

Важно: в @BotFather для вашего бота нужно указать домен мини‑приложения (команда `/setdomain`).

## Установка на телефон (из браузера)

Это приложение можно добавить на главный экран телефона и открывать как обычное “приложение”.

### iPhone / iPad (Safari)

1) Откройте сайт приложения в **Safari** (не во встроенном браузере Telegram/Instagram и т. п.)
2) Нажмите **Поделиться** (квадрат со стрелкой вверх)
3) Выберите **На экран «Домой»** / **Add to Home Screen**
4) Подтвердите добавление

### Android (Chrome/Edge)

1) Откройте сайт приложения в **Chrome** (или **Edge**)
2) Нажмите меню **⋮** → **Установить приложение** (или **Добавить на главный экран**)
3) Подтвердите

Если пункта “Установить” нет — обновите страницу, убедитесь что адрес начинается с `https://`, и попробуйте открыть сайт именно в системном браузере (не во встроенном).

## Запуск бота

1) Установите зависимости:

```powershell
cd bot
python -m venv .venv
.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
```

2) Настройте переменные окружения:

- `BOT_TOKEN` — токен от @BotFather
- `WEBAPP_URL` — HTTPS URL, где доступен `webapp/index.html` (корень мини‑приложения)

Пример лежит в `bot/.env.example`.

3) Запустите:

```powershell
python main.py
```

## Как пользоваться в Telegram

1) Напишите боту `/start`
2) Нажмите кнопку **Открыть погоду**
3) Выберите город (или геолокацию) и единицы измерения
4) Нажмите **Отправить прогноз** (Telegram MainButton)
5) Бот пришлёт прогноз сообщением в чат

## Источники данных

- Прогноз + геокодинг: Open‑Meteo (без API‑ключа)
