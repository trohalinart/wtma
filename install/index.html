Установка на телефон

Добавьте «Погоду» на главный экран — будет открываться как приложение.

Открыть

iPhone / iPad (Safari)

  1. Откройте сайт приложения в Safari (не во встроенном браузере Telegram/Instagram и т. п.).
  2. Нажмите Поделиться (квадрат со стрелкой вверх).
  3. Выберите На экран «Домой» / Add to Home Screen.
  4. Подтвердите добавление.

Android (Chrome / Edge)

  1. Откройте сайт приложения в Chrome (или Edge).
  2. Нажмите меню ⋮ → Установить приложение (или Добавить на главный экран).
  3. Подтвердите.
Если пункта “Установить” нет — обновите страницу, убедитесь что адрес начинается с https://, и попробуйте открыть сайт именно в системном браузере (не во встроенном).
